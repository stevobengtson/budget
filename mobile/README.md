# Mobile apps

Native clients for the Budget API. Both talk to the same JSON API served by the
Go web binary under `/api/v1` (see `internal/web/apiv1`).

| | Stack | Build with |
|---|---|---|
| `ios/` | Swift + SwiftUI | Xcode (project generated by XcodeGen) |
| `android/` | Kotlin + Jetpack Compose | Android Studio (Gradle) |

## Run the API locally first

Both apps' first screen calls `GET /api/v1/health`. Start the server from the
repo root:

```bash
task web        # serves on :8080
```

- **iOS Simulator** reaches it at `http://localhost:8080`.
- **Android emulator** reaches the host at `http://10.0.2.2:8080` (localhost
  inside the emulator is the emulator itself).

See `ios/README.md` and `android/README.md` for per-platform setup.
